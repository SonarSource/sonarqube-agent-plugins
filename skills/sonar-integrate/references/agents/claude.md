# Claude web

Ask the user to:

1. Open **Customize > Connectors** in [Claude](https://claude.ai), then **+ Add > Add custom connector**.
2. Name the connection `sonarqube`, enter the selected URL, and click **Continue**. Review the detected authentication settings and continue.
3. Choose **Sign in now** and **Use Claude's published identity**. Click **Add** and complete sign-in.
4. In the chat, open **+ > Connectors** and enable the connection.

For Team or Enterprise accounts, an owner or authorized administrator first opens **Organization settings > Connectors > Add > Custom > Web**, then follows steps 2–3. Members open **Customize > Connectors**, select **Connect**, and enable it in their chat.

Sources: [Claude custom connectors](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp), [Claude Code MCP setup](https://code.claude.com/docs/en/mcp).
