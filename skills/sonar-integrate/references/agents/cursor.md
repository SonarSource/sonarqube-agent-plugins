# Cursor Cloud Agents

Ask the user to:

1. Open [Cursor Agents](https://cursor.com/agents) and select **Customize > MCPs**.
2. Add `sonarqube` with the selected URL and complete OAuth sign-in.
3. Turn on the server's toggle so its tools are available to the cloud agent.

Source: [Cursor MCP documentation](https://cursor.com/docs/mcp).
